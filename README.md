# 🖥️ Linux System Monitoring Tool

A lightweight Bash-based system monitoring tool for Linux systems.  
It provides real-time insights into system performance, security, and health status.

---

## 🚀 Features

- CPU usage monitoring
- Memory usage tracking
- Disk usage analysis
- Running processes overview
- System uptime display
- Failed login detection (security check)
- System health status (GOOD / WARNING / CRITICAL)
- Log file generation for auditing

---
